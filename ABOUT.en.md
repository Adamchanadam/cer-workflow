# About CER Workflow

CER Workflow helps AI handle long-running, multi-batch, interruption-prone work, or work that needs independent acceptance.

It separates responsibility clearly: `🚀 C:` thinks through the goal, sources, boundary, and acceptance; the same persistent `E1:` writes files; a fresh `R1:` validates only when needed. Before work starts, CER must prove that the return path works, so state does not become scattered across tasks.

This repository provides public, installable CER Core v1 content: Traditional Chinese and English Skill packages, usage documentation, release notes, and infographics. Full operating procedure belongs only to each Skill package's `references/`.

Repository description:
