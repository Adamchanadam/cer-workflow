# Release Notes

## v0.1.0

Initial public preview of CER Workflow.

Included:

- CER Core v1 as an installable Codex skill
- Human overview
- Portable Markdown AI protocol
- Role title rules for `C:`, `E1:`, `R1:`, and `E2:`
- Session/thread receipt rules for cross-task work
- Four-color checkpoint timing
- Knowledge-base scoping for professional tasks

Known boundary:

- CER Core v1 is standalone.
- Agent Handoff Kit adapter work is documented as a v2 boundary and is not part of the installed skill.
- A real platform run still needs to prove direct-push `ready` and result receipts before claiming full v1 acceptance.
